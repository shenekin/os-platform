

### Upgrade a local `.deb` file using **APT**

This resolves **dependencies automatically**.

```bash
sudo apt update
sudo apt install ./package-name.deb
```

🔹 If an older version is installed, **APT upgrades it automatically**
🔹 Works on Ubuntu 24.x
🔹 Preferred over `dpkg`

---

## ⚠️ Manual Method (Not Recommended Alone)

### Using `dpkg` (no dependency resolution)

```bash
sudo dpkg -i package-name.deb
```

If dependencies fail:

```bash
sudo apt --fix-broken install
```

---

## 🔁 Upgrade an Already Installed Package (Repo-based)

If the package comes from a repository:

```bash
sudo apt update
sudo apt upgrade package-name
```

Or upgrade everything:

```bash
sudo apt full-upgrade
```

---

## 🧹 Clean Old / Broken Packages

After upgrading:

```bash
sudo apt autoremove
sudo apt autoclean
```

---

## 🔍 Verify Version

Check installed version:

```bash
dpkg -l | grep package-name
```

Or:

```bash
apt policy package-name
```

---

## 🔐 Handle Configuration File Prompts

During upgrade, Ubuntu may ask:

```text
Configuration file '/etc/xxx.conf'
 ==> Package distributor has shipped an updated version.
```

**Options:**

* `Y` → keep current config (safe for servers)
* `N` → use maintainer version

---

## 🚫 Downgrade (if needed)

```bash
sudo apt install package-name=version
```

Lock version:

```bash
sudo apt-mark hold package-name
```

---

## 🧠 Best Practices (Ubuntu 24.x)

✔ Use `apt install ./file.deb`
✔ Avoid `dpkg -i` unless necessary
✔ Always run `apt --fix-broken install` if errors
✔ Prefer repository-managed packages

---

## 🆘 Common Errors & Fixes

### ❌ “dependency problems – leaving unconfigured”

```bash
sudo apt --fix-broken install
```

### ❌ “package architecture (amd64) does not match”

```bash
dpkg --print-architecture
```
