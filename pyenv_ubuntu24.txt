## 1️⃣ Install system dependencies (Ubuntu 24.04)

These are **required**, otherwise Python builds will fail.

```bash
sudo apt update
sudo apt install -y \
  build-essential \
  curl \
  git \
  libssl-dev \
  zlib1g-dev \
  libbz2-dev \
  libreadline-dev \
  libsqlite3-dev \
  llvm \
  libncursesw5-dev \
  xz-utils \
  tk-dev \
  libxml2-dev \
  libxmlsec1-dev \
  libffi-dev \
  liblzma-dev
```

## 2️⃣ Install pyenv

### Recommended: official installer

```bash
curl https://pyenv.run | bash
```

This installs:

* `pyenv`
* `pyenv-virtualenv`
* `pyenv-update`

---

## 3️⃣ Configure shell (⚠️ REQUIRED)

### For **bash**

```bash
nano ~/.bashrc
```

Add **at the bottom**:

```bash
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"

eval "$(pyenv init --path)"
eval "$(pyenv init -)"
eval "$(pyenv virtualenv-init -)"
```

Apply:

```bash
source ~/.bashrc
```

---

### For **zsh** (if using oh-my-zsh)

```bash
nano ~/.zshrc
```

Add:

```bash
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"

eval "$(pyenv init --path)"
eval "$(pyenv init -)"
eval "$(pyenv virtualenv-init -)"
```

Apply:

```bash
source ~/.zshrc
```

## 5️⃣ Install Python versions

### List available versions

```bash
pyenv install --list
```

### Install common versions

```bash
pyenv install 3.10.14
pyenv install 3.11.9
pyenv install 3.12.3
```

⚠️ Python 3.12 works fine on Ubuntu 24.04 with the deps above.

## 6️⃣ Set Python version

### Global (system-wide for user)

```bash
pyenv global 3.11.9
```

### Per-project (recommended)

```bash
cd your_project
pyenv local 3.11.9
```

Creates:

```
.python-version
```


```bash

```

### Deactivate


### Per-project auto-activate

```bash

```

## 9️⃣ Common issues & fixes

### ❌ `pyenv: command not found`

➡️ Shell not configured
✔️ Re-run `source ~/.bashrc` or restart terminal

---

### ❌ Python build failed

➡️ Missing libs
✔️ Reinstall deps:

```bash
sudo apt install --reinstall libssl-dev zlib1g-dev libbz2-dev libreadline-dev libsqlite3-dev
```

---

### ❌ pyenv ignored, system python used

➡️ PATH order wrong
✔️ Ensure `.pyenv/bin` is **before** `/usr/bin`

Check:

```bash
echo $PATH
```
