该方法适合已安装 Linux 版微信（通常是 4.0 及以上版本）的情况，核心是删除微信的进程锁定文件，让系统可重复启动微信实例。操作步骤如下：

    先启动一次微信并关闭，确保生成基础配置文件。
    打开终端，输入命令删除锁定文件：rm -f ~/.xwechat/lock/lock.ini。
    随即启动微信：若微信安装路径为默认，可直接在终端输wechat，或点击桌面快捷方式。每要多开一个账号，就重复一次 “删除锁定文件 + 启动微信” 的步骤，即可登录新账号。
    也可制作脚本简化操作，新建文本文件命名为wechat-multi.sh，写入如下内容：

bash
Run

#!/bin/bash
if [ -f "$HOME/.xwechat/lock/lock.ini" ]; then
  rm -f "$HOME/.xwechat/lock/lock.ini"
fi
/usr/bin/wechat %U

    保存后给脚本加执行权限：chmod +x wechat-multi.sh，之后双击脚本或终端执行./wechat-multi.sh，就能快速启动新的微信实例。
